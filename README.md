Landing page completa para capturar clientes interessados nos **5 perfumes Jequiti mais pesquisados no Brasil**, com compra pelo **WhatsApp**.

## Arquivos
| Arquivo | O quê |
|---|---|
| `index.html` | A landing page completa (1 arquivo, sem dependências) |
| `ESTRATEGIA-SEO-GEO.md` | Relatório completo: top 5 sites, top 5 produtos, Google Trends, SEO, GEO, design e roadmap |
| `robots.txt` | SEO + liberação de bots de IA (GEO) |
| `llms.txt` | Resumo citável para ChatGPT/Gemini/Perplexity |
| `sitemap.xml` | Sitemap para o Google |

## Como usar
1. No `index.html`, troque `WHATSAPP_NUMBER` pelo seu número (DDI+DDD, só dígitos).
2. Troque `https://jequiti.example.com/` pelo seu domínio real (canonical, OG, JSON-LD, `robots.txt`, `sitemap.xml`).
3. Publique em GitHub Pages, Netlify ou qualquer hospedagem.

## Recursos da página
- Botão de WhatsApp por produto (mensagem pré-preenchida) + botão flutuante + CTA fixa no mobile
- Quiz “Qual perfume é a sua cara?” com recomendação automática
- Comparativo, prova social, kits, FAQ e Guia citável (SEO + GEO)
- Dados estruturados JSON-LD (FAQ, ItemList, LocalBusiness) para Google e IAs
